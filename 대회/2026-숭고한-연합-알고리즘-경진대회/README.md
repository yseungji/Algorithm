## 문제별 풀이 요약

### A. 정12각형

문제에서 주어진 넓이 공식은 `3 × r²`입니다. 각 테스트 케이스마다 반지름 `r`을 입력받아 공식을 바로 적용했습니다.

### B. MOBIS 프로젝트 신청하기

문자열에서 `A`, `C`, `E`, `I`에 해당하는 참가자 수를 셉니다. 전문 분야 참가자가 4명인 경우 또는 모든 참가자가 `O`인 경우에만 팀을 만들 수 있다는 조건을 이용했습니다.

### C. std.IO

문자열을 뒤에서부터 순회하면서 `O`는 0, `I`는 1로 저장했습니다. 마지막에 선행 비트 1을 추가한 뒤 각 비트에 대응하는 2의 거듭제곱을 더해 정답을 구했습니다.

### D. 퍼리와 쿼리

각 퍼리가 내민 부위가 도착하는 위치에 해당 퍼리의 번호를 기록합니다. 전체 구간이 완벽하다는 조건을 이용하면 이 배열은 순열이 됩니다. 각 쿼리에서는 해당 구간의 값 합과 원래 인덱스 합을 비교하고, 양 끝의 값도 구간 안에 있는지 확인했습니다.

### E. 돌려돌려 돌림판

회전할 때마다 배열을 실제로 이동시키지 않고 `cur`에 현재 맨 위 칸의 위치만 저장했습니다. 시계 방향과 반시계 방향 회전을 모듈러 연산으로 반영하고, 3번 쿼리에서는 `cur`로부터 원하는 칸의 번호를 계산했습니다.

### F. 색종이 자르기

두 점이 서로 다른 조각으로 처음 분리되는 순간 두 점의 가중치 곱이 비용에 정확히 한 번 포함됩니다. 따라서 자르는 방법과 순서에 관계없이 총비용은 모든 서로 다른 두 점의 가중치 곱의 합입니다. 누적 가중치 합을 관리하면서 각 가중치와 뒤쪽 가중치 합의 곱을 더해 선형 시간에 계산했습니다.
